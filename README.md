
## 3. Project Structure

The repository is organized according to the different parts of the Graph Mining project.

| Directory | Description |
|---|---|
| `data/` | LastFM dataset and preprocessed data |
| `notebooks/` | Data exploration and Python analysis notebooks |
| `cypher/` | Neo4j Cypher queries |
| `src/` | Reusable Python source code |
| `results/` | Generated plots, statistics, tables, and analysis results |
| `docs/` | Graph schema, methodology, and references |
| `presentation/` | Final project presentation |

### Notebooks Organization

The notebooks follow the logical progression of the project:

| Notebook | Description |
|---|---|
| `01_data_exploration.ipynb` | Dataset exploration and understanding |
| `02_graph_properties.ipynb` | Degree distribution, distances, triangles, and betweenness |
| `03_communities_analysis.ipynb` | Louvain, Label Propagation, and community analysis |
| `04_advanced_analysis.ipynb` | Advanced analysis (D1, D2, or D3) |
| `05_insights.ipynb` | Interpretation of results and answers to Q12 |
